# ロゴメーカー

お店やブランドの名前を入れて、マーク・フォント・配色をえらぶだけでロゴを作れる無料ツールです。

https://novalis-lab.github.io/logo-maker/

- マークの形（まる・かど丸・ひし形・六角形・輪・四角・形なし）と中身（頭文字・記号・絵文字・好きな1〜2文字）をえらべます
- 並べ方は「横ならび・たてならび・文字だけ・マークだけ」
- フォントは Google Fonts（無料・商用利用OK）から17種類
- 🎲 で、フォント・配色・マークをおまかせで作れます
- 保存は PNG（透過も可）・SNSアイコン用の正方形（1024×1024）・ヘッダー用の横長（1500×500）
- ロゴは端末の中（canvas）だけで作り、どこにも送りません（入れた文字と設定だけ、この端末に保存）
- 1ファイル（index.html）だけで動きます
