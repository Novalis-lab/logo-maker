# かんたんロゴメーカー

お店の名前・屋号・チーム名を入れるだけで、シンプルなロゴとアイコン画像を無料で作れるツールです。登録不要。

https://novalis-lab.github.io/logo-maker/

- 入力：ロゴの文字（必須・20文字まで）／サブの文字／マークの文字（1〜2文字・空欄ならロゴの1文字目）
- レイアウト：横並び・縦並び・文字だけ・マークだけ
- マークの形：丸・角丸・葉っぱ形・六角形・ひし形・輪っか
- フォント：日本語が使える Google Fonts 9種類（すべて商用利用OK）
- 色：文字・マーク・マークの文字・背景の4色＋配色セット8種類、背景の透明化
- 🎲 おまかせで作る
- 保存：ロゴ（プレビューの4倍の高画質PNG）／アイコン用（512×512 PNG）
  - iPhone でダウンロードできないときのため、保存した画像を画面にも出し、長押しで保存できるようにしています
- 描画は canvas。フォントの読み込みを待ってから描きます
- 外部API・APIキーなし。index.html の1ファイルだけで動きます
- 入れた文字と設定は、この端末（localStorage）にだけ保存します

## 手元で確認する方法

`index.html` をブラウザで開くだけで動きます（Mac なら `open index.html`）。
iPhone で試すときは、Mac で `python3 -m http.server 8000` を実行し、同じ Wi-Fi の iPhone から `http://（Macのアドレス）:8000/` を開きます。
